Google Photos Remover

An open-source Chrome extension to bulk-delete your entire Google Photos library. No store listing, no tracking, no trust issues — read the code and install it yourself.

Why this exists

I needed to wipe a Google Photos library but didn't trust the extensions already on the Chrome Web Store. They ask for broad permissions and you can't see what they actually do with your data.

So I built my own. It's ~200 lines of JavaScript, fully open-source, with zero dependencies. You can read every line before you install it. It is deliberately not published to the Chrome Web Store because I don't want to maintain a store listing — and because the whole point is that you install it yourself after reviewing the code.

How to install

  1. Download the ZIP and unzip it (or git clone the repo).
  2. Open chrome://extensions in Chrome (or any Chromium-based browser).
  3. Enable Developer mode (toggle in the top-right).
  4. Click Load unpacked and select the unzipped folder.
  5. The extension icon appears in your toolbar. You're done.
Note: Chrome will show a warning about developer-mode extensions on startup. That's normal for unpacked extensions — just dismiss it.

How to use

  1. Go to photos.google.com and wait for the photo grid to load.
  2. Click the extension icon in the toolbar to open the popup.
  3. Click Start. The extension will begin selecting photos in batches of 500 and deleting them.
  4. The popup shows a live count of deleted items. Click Stop at any time.
Warning: Deleted items are moved to Google Photos Trash, which auto-empties after 60 days. If you want them gone immediately, empty the Trash manually.

How it works

The extension injects a content script into Google Photos pages that:

  1. Finds visible photo/video tiles in the grid.
  2. Clicks each tile's selection checkbox (up to 500 per batch).
  3. Clicks the Delete button in the toolbar.
  4. Confirms the "Move to trash" dialog.
  5. Waits for the grid to refresh, then repeats.

That's it — no network requests, no external servers, no analytics. Everything happens locally in your browser tab.

FAQ

Why isn't this on the Chrome Web Store?

Because the whole point is transparency. I don't want to maintain a store listing and I don't want you to blindly trust a store extension. Install it from source.

Is it safe?

Read the code — it's short. The extension only has permission to run on photos.google.com and does nothing else. It never sends data anywhere.

It stopped deleting / selectors broke

Google Photos updates its DOM from time to time. If the extension stops working, the CSS selectors in content.js may need updating. Open an issue or submit a PR.

Can I recover deleted photos?

Yes — items go to Google Photos Trash and stay there for 60 days before being permanently deleted.
